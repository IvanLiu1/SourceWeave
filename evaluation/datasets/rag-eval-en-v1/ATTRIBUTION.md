# Dataset attribution

This normalized evaluation subset contains material derived from:

- HotpotQA, distractor development split: <https://hotpotqa.github.io/>
- Stanford Question Answering Dataset (SQuAD) 2.0, development split:
  <https://rajpurkar.github.io/SQuAD-explorer/>

The source datasets are distributed under the Creative Commons Attribution-ShareAlike 4.0
International license: <https://creativecommons.org/licenses/by-sa/4.0/>.

The subset selection and normalized JSONL representation were created for the SourceWeave project.
The exact source-file SHA-256 values, sampling seed, selection rules, and counts are recorded in
`manifest.json`.
